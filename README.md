# CNC Code Editor для RichAuto A11

Программа для редактирования кода на станок ЧПУ в формате .nc для контроллера ЧПУ RichAuto A11.

## Особенности:
- Современный интерфейс с тёмной темой (GUI версия)
- Полностью на русском языке
- Поддержка всех параметров: Шаг (Y), Ширина (X), Высота подъёма (Z), Глубина реза (Z), Скорость подачи (F)
- Портативная - работает без установки
- Возможность загрузки, редактирования и сохранения .nc файлов
- Автоматическое извлечение параметров из существующих файлов
- Клавиатурная поддержка (в GUI версии):
  - Ctrl+O - Открыть файл
  - Ctrl+S - Сохранить файл
  - Ctrl+Shift+S - Сохранить как
  - F5 - Сгенерировать код
  - Tab/Shift+Tab - Навигация между элементами
- Генерация файлов в формате y{шаг}x{ширина}.nc
- Справка по контроллеру RichAuto A11

## Установка и запуск:
### Для GUI версии (если доступен tkinter):
1. Убедитесь, что у вас установлен Python 3.x и tkinter
2. Запустите: `python cnc_editor.py`

### Для командной версии (универсальная):
1. Убедитесь, что у вас установлен Python 3.x
2. Запустите: `python cnc_generator.py`

## Использование командной версии:
- Интерактивный режим: `python cnc_generator.py`
- Генерация кода: `python cnc_generator.py generate 40 200 4.000 0.000 300`
- Извлечение параметров: `python cnc_generator.py extract существующий_файл.nc`
- Справка: `python cnc_generator.py help`

## Формат имени файла:
Файлы сохраняются в формате `y{шаг}x{ширина}.nc` (например, `y40x200.nc`)

## Авторство:
