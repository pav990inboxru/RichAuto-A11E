# CNC Code Editor для RichAuto A11

Программа для редактирования кода на станок ЧПУ в формате .nc для контроллера ЧПУ RichAuto A11.

## Особенности:
- Современный интерфейс с тёмной темой
- Полностью на русском языке
- Клавиатурная поддержка:
  - Ctrl+O - Открыть файл
  - Ctrl+S - Сохранить файл
  - Ctrl+Shift+S - Сохранить как
  - F5 - Сгенерировать код
  - Tab/Shift+Tab - Навигация между элементами
- Портативная - работает без установки
- Поддержка всех параметров: Шаг (Y), Ширина (X), Высота подъёма (Z), Глубина реза (Z), Скорость подачи (F)

## Установка и запуск:
1. Скачайте файл cnc_editor.py
2. Убедитесь, что у вас установлен Python 3.x
3. Запустите программу: `python cnc_editor.py`

## Использование:
1. Введите параметры в левой панели
2. Используйте кнопку "Сгенерировать" для создания кода
3. Редактируйте код вручную в правой области
4. Сохраните файл с помощью кнопок "Сохранить" или "Сохранить как"

## Формат имени файла:
Файлы сохраняются в формате `y{шаг}x{ширина}.nc` (например, `y40x200.nc`)

## Авторство:
Разработано Harper_IDS для организации КД-Групп
